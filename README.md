# AI Career Matching — RNU Science Week 2027 Research Concept

A responsive, static website for a proposed student research project about transparent skills matching for entry-level jobs.

## Files
- `index.html` — website content and sections.
- `styles.css` — responsive layout and visual design.
- `script.js` — interactive sample skill-matching demo.
- `research-proposal.md` — structured proposal draft.
- `methodology.md` — experiment and evaluation plan.
- `references.md` — starting sources and literature-search checklist.
- `README.md` — this guide.
- `.gitignore` — common files to exclude from Git.
- `LICENSE` — MIT license for this starter code.

## Run locally
1. Download and extract this ZIP file.
2. Open the extracted folder.
3. Double-click `index.html` to open it in a browser.
4. Try the prototype by entering comma-separated skills.

The website is static: no server, API key, database, or paid service is needed. The demo uses fictional examples and does not send input to a server.

## Publish using GitHub Pages
1. Sign in to GitHub and create a new repository, for example `rnu-ai-career-research`.
2. Choose **Public** if you want the site accessible to everyone. Do not upload personal or confidential data.
3. Upload all files from this folder to the repository root. Do not upload only the ZIP file.
4. Commit the files to the default branch (usually `main`).
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/ (root)`, then click **Save**.
8. Wait for the deployment to finish. GitHub will display the website URL in Settings → Pages, usually `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

If the page does not appear, check that `index.html` is in the repository root and that the Pages deployment completed successfully.

## Before submitting the research paper
- Open the official RNU call and download its required DOCX template.
- Confirm the current instructions and deadline.
- Replace this draft with a 4–6 page English paper formatted using the official template.
- Read and verify the references; add relevant peer-reviewed research.
- Run and document the experiments before writing findings.
- Never present the prototype's illustrative scores as experimental results.

## Research integrity
This repository is a concept and demonstrator, not evidence that the proposed system improves employability. All empirical claims must be supported by completed, documented research.
